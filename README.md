## 功能清单

### 卖货页
- 商品列表 / 卖出记录 双 Tab 切换，切换不闪退
- 指标命名统一为「盈亏」：总盈亏、今日盈亏、已完成销售额、已完成本金、累计本金（全应用原「利润」字样均已改为「盈亏」）
- 卖货页指标默认统计全部历史数据（总盈亏/累计卖出/已完成销售额/已完成本金），仅「今日盈亏」按当天统计
- 「总盈亏」数值右侧附带盈亏率，如 `¥1234.50 · 12.3%`（= 总盈亏 ÷ 已完成本金）
- 总盈亏口径：按商品**当前**进价+运费实时计算，并扣掉**物流单的快递费**（`SUM(售价 − (进价+运费)×数量) − SUM(shipments.totalFee)`）；卖出、改价、改运费、增删物流单都会即时重算，无需重启（统计区间为开区间 `[0, +∞)`，不会因启动时间而漏掉之后的记录）
- 列表滚动时盈亏栏完全收起，商品列表整屏滚动
- 商品列表头部：搜索、分类筛选、**批量删除**（多选后一键删除）、添加物品
- 点商品行右侧的**删除键**直接进入批量删除多选（勾选后一键删除）
- 顶部工具栏：物流单、卖出记录、统计图表、**导出全部**、**导入**

### 单个商品修改页（点商品卡片打开）
- 可改名称、查看/删除各笔进货、切换到货状态、保存备注
- 「进价 ¥X · 含运费 ¥Y · 点击修改」：点该行弹出**两个输入框**（上＝进价、下＝出售价，留空则不改），保存后即时生效；改出售价会同步更新该商品全部卖出记录并重算其盈亏

### 添加物品 / 进货
- 快捷录入框支持多行，框内提示格式：`渠道-物品-成本-时间-备注`，每行一条
- 「批量导入」按钮一次识别多行：第一行填入表单，其余行在点保存时一并写入
- 底部「+」快捷菜单里的「添加物品」直接打开卖货的进货弹窗

### 导出 / 导入（全部商品）
- 导出：全部商品 CSV，列 = 物品名称,渠道,成本价,运费,备注,创建时间,到货状态,分类，写到 `Downloads/Accounting/`
- 导入：选择上述 CSV，同名商品自动跳过，完成后提示导入件数并刷新列表

### 记账页
- 按月分组账单、快捷记账
- 顶部**批量删除**：多选账单后一键删除

## 构建与发布

```bash
# 构建
java -jar tools/apktool.jar b -f -p .work/framework -o artifacts/hengji-rebuilt.apk decoded
# 签名
java -jar tools/uber-apk-signer.jar -a artifacts/hengji-rebuilt.apk \
  --ks tools/keystore/hengji.jks --ksAlias hengji --ksPass hengji2026 --ksKeyPass hengji2026 \
  --allowResign -o artifacts/signed
# 发布到 Downloads（自动 bump 版本号）
powershell -ExecutionPolicy Bypass -File scripts/01-build-apktool.ps1
```

版本号在 `decoded/apktool.yml`（versionName / versionCode）。
